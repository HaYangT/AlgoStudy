# 봉우리의 개수

## 문제 설명

혜역이는 전국 등산 협회의 개발자로 일하고 있다.

그러던 어느 날, 에베레스트산에 휴게소를 짓기 위해 **특정 높이 이상의 봉우리가 몇 개**인지 조사하라는 임무를 받게 되었다.

산은 N개의 봉우리와 N-1개의 길로 이루어진 트리 구조이며, 모든 길은 **정상에서 아래 방향으로 향하는 단방향**이다. 산의 정상은 항상 1번 정점이며, 정상에서 다른 모든 봉우리로 도달할 수 있음이 보장된다.

각 봉우리의 높이는 다음과 같이 정의된다.

> **봉우리의 높이 = 산의 높이 H − 정상에서 해당 봉우리까지의 거리**

혜역이를 도와서 주어진 높이 h 이상인 봉우리가 몇 개인지 알려주는 함수를 구현해 보자.

## 제한 사항

- 1 ≤ N ≤ 100,000
- 1 ≤ H ≤ 1,000,000,000
- 1 ≤ u, v ≤ N
- 1 ≤ d ≤ 100,000
- 1 ≤ Q ≤ 100,000
- 1 ≤ h ≤ H
- 모든 봉우리에 대해 정상으로부터의 거리는 H 이하임이 보장된다.
- 시간 제한: **1초**
- 메모리 제한: **256MB**

## 입력

첫째 줄에 봉우리의 수 N과 산의 높이 H가 공백으로 구분되어 주어진다.

이후 N-1개의 줄에 걸쳐 세 정수 u, v, d가 공백으로 구분되어 주어진다. 이는 u에서 v로 가는 길의 길이가 d라는 의미이다.

다음 줄에 쿼리의 수 Q가 주어진다.

이후 Q개의 줄에 걸쳐 정수 h가 주어진다.

## Return

`int[] result`를 반환한다.

`result[i]`는 i번째 쿼리의 답이며, 높이가 h[i] 이상인 봉우리의 개수이다.

## 예제

### 입력

```
7 200
1 2 10
1 3 20
2 4 5
2 5 15
3 6 10
3 7 25
8
200
190
180
175
170
150
100
1
```

### Return 값

```
[1, 2, 4, 5, 6, 7, 7, 7]
```

### 설명

각 봉우리의 정상으로부터의 거리와 높이는 다음과 같다.

| 정점 | 정상에서의 거리 | 높이 (H − 거리) |
|:---:|:---:|:---:|
| 1 | 0 | 200 |
| 2 | 10 | 190 |
| 3 | 20 | 180 |
| 4 | 15 | 185 |
| 5 | 25 | 175 |
| 6 | 30 | 170 |
| 7 | 45 | 155 |

각 쿼리의 결과:

- h = 200 → 높이가 200 이상인 봉우리: {1} → **1개**
- h = 190 → {1, 2} → **2개**
- h = 180 → {1, 2, 3, 4} → **4개**
- h = 175 → {1, 2, 3, 4, 5} → **5개**
- h = 170 → {1, 2, 3, 4, 5, 6} → **6개**
- h = 150 → 모든 봉우리 → **7개**
- h = 100 → 모든 봉우리 → **7개**
- h = 1 → 모든 봉우리 → **7개**
