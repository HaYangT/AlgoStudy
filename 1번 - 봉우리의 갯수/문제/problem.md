# 봉우리의 갯수

## 문제 설명

혜역이는 전국 등산 협회의 개발자로 취업해서 일하고 있었다.

그러던 어느날, 에베레스트산에 휴게소를 만들기 위해 특정 높이 이상의 봉우리가 몇 개인지 조사를 맡게 되었다.

산의 정상은 1번 정점임이 보장되며, 산은 N개의 봉우리와 N-1개의 단방향 길로 이루어져 있다.

산의 정상에서 다른 모든 정점으로 갈 수 있음이 보장된다.

각 봉우리의 높이는 **산의 높이 H - 정상에서 해당 봉우리까지의 거리**다.

혜역이를 도와서 특정 높이 이상의 봉우리가 몇개 인지 알려주는 프로그램을 만들어 보자.

## 제한 사항

- 1 ≤ N ≤ 100,000
- 1 ≤ H ≤ 1,000,000,000
- 1 ≤ u, v ≤ N
- 1 ≤ d ≤ 100,000
- 1 ≤ Q ≤ 100,000
- 모든 정점에 대해 산 정상에서 봉우리까지의 거리는 H를 넘지 않음이 보장된다.
- 시간 제한: **1초**
- 메모리 제한: **256MB**

## 입력

첫째 줄에 N과 H가 주어진다.

2번째 줄부터 N번째 줄까지 3개의 정수 u, v, d가 주어진다. 이는 u에서 v로 가는 길의 길이가 d라는 것이다.

N+1번째 줄에 쿼리의 횟수 Q가 주어진다.

이후 Q개의 줄에 걸쳐 높이 h가 주어진다.

## 출력

Q개의 줄에 걸쳐 h[i] 이상의 높이에 있는 봉우리의 개수를 출력하라.

## 예제

### 입력

```
7 200
1 2 10
1 3 20
2 4 5
2 5 15
3 6 10
3 7 25
8
200
190
180
175
170
150
100
1
```

### 출력

```
1
2
4
5
6
7
7
7
```

### 설명

각 봉우리의 높이는 다음과 같다.

| 정점 | 정상까지 거리 | 높이 (200 - 거리) |
|:---:|:---:|:---:|
| 1 | 0 | 200 |
| 2 | 10 | 190 |
| 3 | 20 | 180 |
| 4 | 15 | 185 |
| 5 | 25 | 175 |
| 6 | 30 | 170 |
| 7 | 45 | 155 |

- h = 200 → 높이가 200 이상인 봉우리: {1} → **1개**
- h = 190 → {1, 2} → **2개**
- h = 180 → {1, 2, 3, 4} → **4개**
- h = 175 → {1, 2, 3, 4, 5} → **5개**
- h = 170 → {1, 2, 3, 4, 5, 6} → **6개**
- h = 150 → {1, 2, 3, 4, 5, 6, 7} → **7개**
- h = 100 → 전부 → **7개**
- h = 1 → 전부 → **7개**
