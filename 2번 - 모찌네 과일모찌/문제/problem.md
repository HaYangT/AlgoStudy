# 모찌네 과일모찌

## 문제 설명

모찌쿤은 엄청난 미모의 고양이다.

![귀여운모찌쿤](./img/img1.jpg)

모찌쿤은 이름 값을 하기 위해 과일모찌 가게를 열었다.

모찌쿤은 가게 관리를 하고 싶어 했지만, 고양이라서 사람의 언어는 너무나도 어려웠다.

모찌쿤을 도와서 가게 관리 프로그램을 만들어보자.

가게에는 N개의 판매 기록이 쌓여있고, 모찌쿤은 **특정 기간 사이 팔린 상품들의 총 개수**를 궁금해한다.

Q개의 질문에 대해, 각 기간 동안 팔린 상품들을 **이름 사전순**으로 정리해서 알려주자.

## 제한 사항

- 1 ≤ N ≤ 100
- 1 ≤ Q ≤ 100
- 1 ≤ cnt ≤ 1,000
- 상품 이름은 알파벳 소문자로만 이루어져 있으며, 길이는 1 이상 20 이하이다.
- 날짜는 `YYYY:MM:DD` 형식의 문자열로 주어진다. (문자열 비교만으로 날짜 비교가 가능함이 보장된다)
- 각 쿼리의 시작일은 종료일보다 같거나 빠름이 보장된다.
- 시간 제한: **1초**
- 메모리 제한: **256MB**

## 입력

첫째 줄에 판매 기록의 개수 N이 주어진다.

이후 N개의 줄에 걸쳐 날짜 `date`, 상품 이름 `name`, 개수 `cnt`가 공백으로 구분되어 주어진다.

다음 줄에 쿼리의 개수 Q가 주어진다.

이후 Q개의 줄에 걸쳐 시작일 `start`, 종료일 `end`가 공백으로 구분되어 주어진다.

## Return

`String[][] result`를 반환한다.

`result[i]`는 i번째 쿼리에 대한 답이며, 해당 기간(시작일 ≤ date ≤ 종료일) 동안 **1개 이상 팔린** 상품들을 **이름 사전순**으로 정렬한 배열이다.

각 원소는 `"이름 개수"` 형식의 문자열이다.

해당 기간에 팔린 상품이 하나도 없다면 빈 배열을 담는다.

## 예제

### 입력

```
5
2024:01:01 apple 3
2024:01:02 banana 5
2024:01:01 apple 2
2024:01:03 banana 1
2024:01:02 cherry 4
2
2024:01:01 2024:01:02
2024:01:02 2024:01:03
```

### Return 값

```
[
  ["apple 5", "banana 5", "cherry 4"],
  ["banana 6", "cherry 4"]
]
```

### 설명

**쿼리 1: 2024:01:01 ~ 2024:01:02**

| 날짜 | 상품 | 개수 |
|:---:|:---:|:---:|
| 2024:01:01 | apple | 3 |
| 2024:01:01 | apple | 2 |
| 2024:01:02 | banana | 5 |
| 2024:01:02 | cherry | 4 |

- apple: 3 + 2 = **5**
- banana: **5**
- cherry: **4**

사전순으로 정렬 → `["apple 5", "banana 5", "cherry 4"]`

**쿼리 2: 2024:01:02 ~ 2024:01:03**

| 날짜 | 상품 | 개수 |
|:---:|:---:|:---:|
| 2024:01:02 | banana | 5 |
| 2024:01:02 | cherry | 4 |
| 2024:01:03 | banana | 1 |

- banana: 5 + 1 = **6**
- cherry: **4**

사전순으로 정렬 → `["banana 6", "cherry 4"]`
